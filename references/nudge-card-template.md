# 일정 카드 + 통합 보강 질문 템플릿

2단계에서 사용자에게 출력하는 카드 포맷 정의서. 시각적 일관성과 인지 부하 최소화가 핵심.

---

## 1. 기본 카드 구조

```
📅 일정 미리보기
─────────────────────────
제목:   {title}
시작:   {start_date} ({weekday}) {start_time}
종료:   {end_date} ({weekday}) {end_time}  ← {duration_note}
장소:   {location}
알림:   {reminders_text}
반복:   {recurrence_text}
캘린더: {calendar}
나챗방: {memo_text_summary}
─────────────────────────
```

**필드 표시 규칙**:
- 채워진 슬롯만 표시
- 비어 있는 슬롯은 줄 자체를 생략 (단, `캘린더`는 빈 상태로 표시하여 묻는 신호 보냄)
- 자동 적용 항목은 `{duration_note}`에 `1시간 (자동)`, `(기본)`, `(자동 감지)` 등 명시

---

## 2. 통합 보강 질문 구성 로직

빈 슬롯에 따라 동적으로 질문을 구성한다. **모두 한 번에 묻고, 자연어 답변과 부분 응답을 모두 허용**한다.

### 2-1. 묻는 우선순위

1. **캘린더 미선택** → 반드시 첫 줄에 묻기 (필수)
2. **핵심 4항목 중 비어 있는 것**: 종료시각·알림·장소·반복
3. 모든 항목이 채워졌으면 → 곧바로 4단계 최종 확인으로 이동

### 2-2. 질문 문구 템플릿

```
{캘린더_질문}
{보강_질문}
바로 등록하려면 "그대로"라고 답해주세요.
```

#### 캘린더 질문 (캘린더가 미선택일 때만)

```
어느 캘린더에 등록할까요? (카카오 / 구글 / 둘다)
```

#### 보강 질문 (비어 있는 핵심 4항목에 따라)

비어 있는 항목 개수에 따라 부드럽게 표현:

| 빈 항목 | 질문 문구 |
|---------|---------|
| 4개 모두 | "장소·알림·반복 중 추가할 게 있으면 자연어로 같이 알려주세요." |
| 3개 | "{항목들} 중 필요한 게 있으면 자연어로 알려주세요." |
| 2개 | "{항목들} 같이 정하시겠어요?" |
| 1개 | "{항목} 정하시겠어요?" |
| 0개 | (보강 질문 생략) |

**항목 한국어 표현**:
- `end_time` 비어있을 때 → "종료시각"
- `reminders` 비어있을 때 → "알림"
- `location` 비어있을 때 → "장소"
- `recurrence` 비어있을 때 → (이건 보통 묻지 않음 — 사용자가 반복이라고 말 안 했으면 단발성이라고 추정)

## 3. 카드 출력 예시

### 예시 A — 최소 정보 입력

**사용자 입력**: "내일 3시 회의"

**Claude 응답**:
```
📅 일정 미리보기
─────────────────────────
제목:   회의
시작:   2026-05-14 (목) 15:00
종료:   2026-05-14 (목) 16:00  ← 1시간 (자동)
─────────────────────────

어느 캘린더에 등록할까요? (카카오 / 구글 / 둘다)
장소·알림 중 추가할 게 있으면 자연어로 같이 알려주세요.
바로 등록하려면 "그대로"라고 답해주세요.
```

### 예시 B — 풍부한 정보 입력

**사용자 입력**: "다음 주 월요일 10시부터 11시 반까지 본관 회의실에서 학부모 상담 잡아줘. 30분 전 알림."

**Claude 응답**:
```
📅 일정 미리보기
─────────────────────────
제목:   학부모 상담
시작:   2026-05-18 (월) 10:00
종료:   2026-05-18 (월) 11:30
장소:   본관 회의실
알림:   30분 전
─────────────────────────

어느 캘린더에 등록할까요? (카카오 / 구글 / 둘다)
바로 등록하려면 "그대로"라고만 답해주세요.
```

### 예시 C — 캘린더 명시 + 추가 정보 풍부

**사용자 입력**: "구글 캘린더에 매주 화요일 오후 2시 팀회의 추가. 연말까지. 30분전 알림."

**Claude 응답**:
```
📅 일정 미리보기
─────────────────────────
제목:   팀회의
시작:   매주 화요일 14:00
종료:   매주 화요일 15:00  ← 1시간 (자동)
반복:   매주 화요일 (~ 2026-12-29까지)
알림:   30분 전
캘린더: 구글
─────────────────────────

장소 추가하시겠어요? 없으면 "그대로"라고 답해주세요.
```

### 예시 D — 모든 항목 채워짐

**사용자 입력**: "구글 캘린더에 내일 오후 3시부터 5시까지 본관 회의실에서 부서 회의, 30분 전 알림"

**Claude 응답** (보강 단계 생략, 바로 최종 확인으로):
```
📅 등록 정보 확인
─────────────────────────
제목:   부서 회의
시작:   2026-05-14 (목) 15:00
종료:   2026-05-14 (목) 17:00
장소:   본관 회의실
알림:   30분 전
캘린더: 구글
─────────────────────────

이대로 등록할까요? (예 / 수정 / 취소)
```

## 4. 종일 일정 카드 변형

```
📅 일정 미리보기
─────────────────────────
제목:   출장
일자:   2026-05-14 (목) ~ 2026-05-15 (금)  ← 종일 (자동)
─────────────────────────
```

종일 일정은 `시작`/`종료` 대신 `일자` 한 줄로 표시.

---

## 5. 반복 일정 카드 변형

종료 시점이 명시된 경우:
```
반복:   매주 화요일 (~ 2026-12-29까지)
```

횟수 기반:
```
반복:   매주 화요일 (10회)
```

종료 미명시 (무한):
```
반복:   매주 화요일 (계속)
```

---

## 6. 이모지 사용 규칙

각 줄 머리에 일관된 이모지를 사용하지 않는다. 이유: 카드 위쪽 `📅` 하나로 충분하며, 줄마다 이모지를 붙이면 시각적 노이즈가 커진다.

다만 강조가 필요한 곳에만 사용:
- `⚠️` — 카카오 경고 (4단계에서만)
- `✅` — 최종 등록 완료 메시지
- `❌` — 실패 메시지
- `⏰` — 알림 설정 완료 안내

---

## 7. 카드 출력 시 절대 금지

1. **빈 슬롯을 "미정", "없음" 등으로 채우지 않는다.** 줄 자체를 생략한다.
2. **사용자가 답하지 않은 항목을 추측해서 카드에 넣지 않는다.**
3. **번호 매기기 강요 금지.** 자연어 답변이 우선이다.
4. **카드 출력 후 같은 턴에 MCP를 호출하지 않는다.** 반드시 사용자 응답을 기다린다.

---

## 8. 나챗방 안내 질문 (항상 포함)

사용자가 나챗방 방식을 이미 정하지 않았다면 보강 질문 마지막에 **항상** 아래 블록을 붙인다. 쉬운 말로 쓰고 전문 용어는 쓰지 않는다.

### 8-1. 카카오가 등록 대상에 포함될 때

```
💬 카카오톡 나챗방으로도 알려드릴까요?
  ① 아침 요약에 포함 — 따로 만들 것 없이, 매일 아침 오늘 일정 요약에 함께 옵니다
  ② 전용 알림 — 정한 날·시각에 이 일정만 따로 메시지가 옵니다
     (예: 매일 9시 "[D-3] 마감: {title}". 원하시는 문구가 있으면 그대로 써 드립니다)
  ③ 안 받기
```

### 8-2. 구글만 등록할 때 (① 제외)

```
💬 카카오톡 나챗방으로도 알려드릴까요?
  ② 전용 알림 — 정한 날·시각에 이 일정만 따로 메시지가 옵니다
  ③ 안 받기
```

### 8-3. ②를 골랐는데 시각·기간이 없을 때

```
전용 알림을 언제 보낼까요? (예: "14일부터 20일까지 매일 오전 9시")
보낼 문구가 따로 있으면 알려주세요. 없으면 "[D-N] 마감: {title}"로 보냅니다.
```

### 8-4. 카드의 나챗방 줄 표기

| 상태 | 표기 |
|------|------|
| ① | `나챗방: 아침 요약에 포함` |
| ② | `나챗방: 10/14~10/20 매일 09:00 "[D-N] 마감: 제목" (기본)` — 사용자 문구면 `(기본)` 생략 |
| ③ | 줄 생략 |
| 미정 | `나챗방: ?` |

### 8-5. 사용자가 처음부터 나챗방까지 시킨 경우

8-1~8-3 중 이미 답이 나온 부분은 묻지 않는다. 빠진 값(예: 시각)만 다른 보강 질문과 한 번에 묻는다. 모두 채워졌으면 곧바로 최종 확인 카드로 간다.
