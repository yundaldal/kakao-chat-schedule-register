# 추출 규칙 (Extraction Rules)

자연어 입력에서 일정 슬롯을 추출하는 패턴 정의서. 1단계(첫 발화 파싱)와 3단계(응답 파싱) 모두에서 사용한다.

---

## 1. 날짜 표현 → `start_date` / `end_date`

**반드시 `datetime.datetime.now()` 기준으로 동적 계산.** 숫자 하드코딩 절대 금지.

| 사용자 표현 | 변환 규칙 |
|------------|---------|
| "오늘" | 오늘 날짜 |
| "내일" | 오늘 + 1일 |
| "모레" | 오늘 + 2일 |
| "다음 주 월요일" | 다음 주의 월요일 |
| "이번 주 금요일" | 이번 주의 금요일 |
| "이번 주말" | 이번 주의 토요일 (모호하면 사용자에게 확인) |
| "다음 달 첫째 주 화요일" | 해당 날짜 |
| "5월 14일" | 올해 5월 14일 (이미 지났으면 내년) |
| "5/14" | 올해 5월 14일 |
| "2026-05-14" | 그대로 |

**모호한 경우**: "다음 주에" 처럼 요일이 빠지면 사용자에게 "다음 주 며칠인가요?"라고 묻는다. 추측 금지.

---

## 2. 시각 표현 → `start_time` / `end_time`

| 사용자 표현 | 변환 결과 |
|------------|---------|
| "3시", "오후 3시" | 15:00 |
| "오전 3시", "새벽 3시" | 03:00 |
| "오전 9시" | 09:00 |
| "오후 2시 반" | 14:30 |
| "오후 2시 30분" | 14:30 |
| "15:00", "3:00 PM" | 15:00 |
| "정오" | 12:00 |
| "자정" | 00:00 |

**오전·오후 미명시 시 추론 규칙**:
- 1~6시 → 오후(13:00~18:00)로 추정하되 사용자에게 한 번 확인
- 7~11시 → 오전으로 추정
- 12시는 항상 정오 12:00 (자정은 "자정"으로 명시될 때만)

**카카오 캘린더용 5분 단위 검증**:
- 13:07, 14:23 같은 비-5분단위 입력 시 → "13:05나 13:10 중 어느 쪽이 좋으세요?"

---

## 3. 종일 일정 → `all_day`

다음 키워드가 있으면 `all_day = true`로 설정:

- 직접 표현: "종일", "하루 종일", "온종일"
- 묵시 표현: "출장", "연차", "휴가", "체험학습", "워크숍 1일차" 등
- 기간 표현: "월요일부터 수요일까지" (2일 이상이면 종일로 추정)

`all_day = true`인 경우 카카오는 `startAt`/`endAt`를 `T00:00:00`으로 설정해야 함.

---

## 4. 제목 추출 → `title`

명사구 추출 우선순위:

1. **명시적 제목 라벨**: "제목은 ~", "건은 ~"
2. **행위 명사**: "회의", "상담", "약속", "통화", "면담", "워크숍", "교육", "출장", "회식", "식사" 등
3. **수식어 + 행위 명사**: "부서 회의", "학부모 상담", "팀 워크숍", "거래처 미팅"
4. **목적어 + 행위**: "예산 검토 회의", "신규 입학생 면담"

**모호한 경우**: "내일 3시에 시간 좀" 처럼 행위가 없으면 사용자에게 "어떤 일정인가요?"라고 묻는다.

**제목 길이 제한**:
- 카카오: 50자 (초과 시 단축 제안)
- 구글: 무제한 (긴 제목은 description으로 분리 제안)

## 5. 알림 표현 → `reminders` (분 단위 배열)

| 사용자 표현 | 변환 결과 |
|------------|---------|
| "30분 전" | `[30]` |
| "1시간 전" | `[60]` |
| "2시간 전" | `[120]` |
| "1일 전" | `[1440]` |
| "30분 전이랑 1시간 전" | `[30, 60]` |
| "1일 전과 1시간 전" | `[1440, 60]` |
| "알림 없음", "필요없어", "안 알려도 돼" | `[]` |
| (응답 없음) | 보강 질문에서 묻기 |

**카카오 제약**: 최대 2개까지만 지원. 3개 이상 추출되면 우선순위 묻기.
- 카카오 범위: -1440 ~ 43200분 (5분 단위)

**구글 제약**: 개수 제한 없음. method는 기본 `popup`. "이메일로 알림"이라고 명시되면 `email`로 변경.

## 6. 장소 표현 → `location`

| 사용자 표현 | 추출 결과 |
|------------|---------|
| "회의실 A에서" | `회의실 A` |
| "본관 3층" | `본관 3층` |
| "줌으로", "구글미트로" | `Zoom` / `Google Meet` (+ 구글이면 `addGoogleMeetUrl=true`) |
| "사무실" | `사무실` |
| "스타벅스 OO점" | `스타벅스 OO점` |
| "OO시 OO센터" | `OO시 OO센터` |

**카카오 전용**: `location.name` (장소명, 100자 제한) + `location.address` (주소, 선택). 사용자가 둘 다 말하면 분리, 하나만 말하면 `name`에만 넣음.

**구글**: 자유 텍스트 단일 필드.

## 7. 반복 표현 → `recurrence` (RFC 5545 RRULE)

| 사용자 표현 | RRULE |
|------------|------|
| "매일" | `FREQ=DAILY` |
| "평일 매일" | `FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR` |
| "매주" | `FREQ=WEEKLY` (해당 요일) |
| "매주 화요일" | `FREQ=WEEKLY;BYDAY=TU` |
| "주마다", "한 주에 한 번" | `FREQ=WEEKLY` |
| "격주" | `FREQ=WEEKLY;INTERVAL=2` |
| "매월", "매달" | `FREQ=MONTHLY` |
| "매월 첫째 주 월요일" | `FREQ=MONTHLY;BYDAY=1MO` |
| "매년", "매해" | `FREQ=YEARLY` |
| "이번 주만", "한 번만" | (반복 없음) |

**종료 시점 표현**:

| 사용자 표현 | RRULE 추가 |
|------------|-----------|
| "연말까지" | `;UNTIL=YYYY1231T235959Z` (올해 연말) |
| "6월까지" | `;UNTIL=YYYY0630T235959Z` |
| "5번", "다섯 번" | `;COUNT=5` |
| "10주간" | `;COUNT=10` |

**카카오 형식 예시**: `FREQ=WEEKLY;UNTIL=20261231T000000Z`
**구글 형식 예시**: `RRULE:FREQ=WEEKLY;UNTIL=20261231T000000Z`

## 9. 참석자 표현 → `attendees` (구글 전용)

| 사용자 표현 | 추출 |
|------------|------|
| "user@example.com" | 그대로 |
| "@홍길동", "홍길동 선생님" | 이름만 추출 → 사용자에게 이메일 확인 요청 |
| "팀원들이랑" | 사용자에게 "구체적으로 누구를 초대할까요?" 묻기 |

**중요**: 이메일이 명시되지 않은 사람 이름만 있으면 이메일 검색·추측 금지. 반드시 사용자에게 직접 묻기.

## 10. 건너뛰기 표현 (전환 신호)

다음 표현 중 하나가 응답에 포함되면 보강 단계를 건너뛰고 4단계 최종 확인으로 점프:

- "그대로", "그냥", "괜찮아", "됐어"
- "없어", "없음", "안 해도 돼"
- "바로 등록", "등록해", "확정"
- "오케이", "응", "맞아" (단, 다른 정보가 함께 있으면 그것도 함께 처리)

## 12. 응답 파싱 우선순위

3단계에서 사용자 응답을 처리할 때 다음 순서로 추출한다:

1. **건너뛰기 표현 검사** → 있으면 즉시 4단계로 전환
2. **캘린더 선택 추출** (없으면 다시 묻기)
3. **알림 시간 추출** (분/시간 + "전" 패턴)
4. **장소 추출** (장소 키워드 + 명사)
5. **반복 표현 추출** (매주/매월/매일 등)
6. **종료시각 명시 추출** ("4시까지", "1시간 동안" 등)

복합 응답에서는 위 6가지를 동시에 추출한다. 충돌 시 가장 구체적인 표현을 우선한다.

## 13. 나챗방 표현 → `memo_mode` / `memo_text` / `memo_time` / `memo_start` / `memo_end`

| 사용자 표현 | 결과 |
|------------|------|
| "나챗방", "나와의 채팅", "나에게 보내기", "카톡으로 나한테" | 나챗방 원함 (방식 미정이면 ①/② 묻기) |
| "아침 요약에", "요약에 나오게" | `memo_mode = ①` |
| "매일 9시에 나챗방으로", "D-day 알림" | `memo_mode = ②` + 시각 추출 |
| "나챗방은 됐어", "카톡 알림은 필요 없어" | `memo_mode = ③` |
| "'○○'라고 보내줘", "문구는 ○○" | `memo_text = ○○` (그대로 사용) |
| "14일부터 20일까지", "마감 3일 전부터" | `memo_start` / `memo_end` (절대일자로 변환) |

- `memo_text`는 사용자의 말을 고치지 않고 그대로 쓴다. 200자 넘으면 줄이자고 제안.
- "마감 N일 전부터 매일"은 `memo_start = 마감일 - N`, `memo_end`는 마감 당일 포함 여부를 확인한다.
- 시각이 없으면 추측하지 않고 묻는다.
