# 암묵지 자동 적용표 (Tacit Defaults)

사용자가 명시하지 않은 종료시각·일정 속성에 대해 **명확하고 보편적인 기본값**만 자동 적용한다. 모든 자동 적용은 일정 카드에 `(자동)` 또는 `(기본)` 으로 명시하여 사용자가 즉시 인지·수정할 수 있도록 한다.

특정 직군·도메인 디폴트는 포함하지 않는다 (범용 스킬 유지).

---

## 1. 종료시각 자동 적용

`title`에서 행위 명사를 식별하여 아래 표대로 `end_time = start_time + duration`을 적용한다.

| 행위 키워드 | 자동 duration | 카드 표기 |
|----------|------------|---------|
| 회의, 미팅, 회의실 | 1시간 | `1시간 (자동)` |
| 약속 | 1시간 | `1시간 (자동)` |
| 점심, 저녁, 식사, 회식 | 1시간 | `1시간 (자동)` |
| 통화, 콜, 전화 | 30분 | `30분 (자동)` |
| 교육, 세미나, 워크숍, 연수 | 2시간 | `2시간 (자동)` |
| 상담 | 1시간 | `1시간 (자동)` |
| 면담, 면접 | 1시간 | `1시간 (자동)` |
| 진료, 병원 | 30분 | `30분 (자동)` |
| 운동, 헬스, 요가 | 1시간 | `1시간 (자동)` |
| 행사, 이벤트 | 2시간 | `2시간 (자동)` |
| **(분류 불가)** | 1시간 | `1시간 (기본)` |

---

## 2. 종일 자동 적용

다음 키워드가 `title`에 포함되면 `all_day = true`로 자동 설정:

- 출장, 외근
- 연차, 휴가, 반차 (반차는 반나절)
- 체험학습
- 워크숍 1박2일, 워크숍 2박3일 등 다일자

카드 표기: `종일 (자동)`

---

## 3. 알림 자동 적용

알림은 **자동 적용하지 않는다.** 사용자가 명시하지 않으면 보강 질문에서 묻는다.

이유:
- 알림은 사용자별 선호도가 크고
- 카카오는 알림이 최대 2개로 제한되어 신중한 선택이 필요하며
- "알림 없이 등록"도 정당한 선택지이기 때문

---

## 4. 장소 자동 적용

장소도 **자동 적용하지 않는다.** 사용자가 명시하지 않으면 보강 질문에서 묻고, 응답이 없으면 비워둔다.

---

## 5. 반복 자동 적용

반복도 **자동 적용하지 않는다.** 단, 사용자 발화에 명백한 반복 신호가 있으면 추출한다:

- "매주", "매월", "매일", "격주" 등 → `recurrence` 자동 설정
- 카드 표기: `매주 화요일 (자동 감지)`

---

## 6. 시간대(timeZone) 자동 적용 — 구글 전용

구글 캘린더는 timeZone 미지정 시 `Asia/Seoul`을 자동 적용한다.

카드 표기는 생략 (한국 사용자에게는 당연한 디폴트).

---

## 7. 색상 자동 적용

색상은 **자동 적용하지 않는다.** 사용자가 명시하지 않으면 캘린더의 기본 색상을 사용한다.

---

## 8. 자동 적용 원칙 요약

| 항목 | 자동 적용 여부 | 카드 표시 |
|------|------------|---------|
| 종료시각 | ✅ (행위 키워드 기반) | `(자동)` 또는 `(기본)` |
| 종일 | ✅ (출장/연차 등) | `(자동)` |
| 알림 | ❌ | 보강 질문 |
| 장소 | ❌ | 보강 질문 |
| 반복 | ⚠️ (명시 표현만) | `(자동 감지)` |
| 시간대 | ✅ (구글, Asia/Seoul) | 표시 생략 |
| 색상 | ❌ | 묻지 않음 (선택적) |
| 참석자 | ❌ | 사용자 명시 시만 |
| 나챗방 방식 | ❌ | 항상 묻기 |
| 나챗방 문구 | ⚠️ (사용자 문구 없을 때만) | `[D-N] 마감: {title}` `(기본)` |
| 나챗방 시각·기간 | ❌ | 보강 질문 |

---

## 9. 사용자 수정 처리

카드에 `(자동)` 표기된 항목을 사용자가 자연어로 수정하면 즉시 반영한다:

- 사용자: "회의 1시간 30분이야"
  → `end_time` 재계산, 카드에 `1시간 30분 (사용자 지정)`으로 표기

- 사용자: "종일 아니야, 오후 2시부터 5시까지"
  → `all_day = false`, `start_time = 14:00`, `end_time = 17:00`

- 사용자: "반복 없어"
  → `recurrence = null`
