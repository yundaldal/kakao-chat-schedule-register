# 최종 확인 게이트 (Confirmation Gate)

4단계 최종 확인 및 5단계 MCP 호출의 안전 절차 정의서. **이 단계를 건너뛰고 MCP를 호출하면 안 된다.**

---

## 1. 최종 확인 카드 출력

모든 슬롯이 정해진 후, 등록 직전에 반드시 아래 카드를 출력한다.

### 1-1. 구글 캘린더만 등록하는 경우

```
📅 등록 정보 확인
─────────────────────────
제목:   {title}
시작:   {start_date} ({weekday}) {start_time}
종료:   {end_date} ({weekday}) {end_time}
장소:   {location}
알림:   {reminders_text}
반복:   {recurrence_text}
참석자: {attendees_text}
캘린더: 구글
─────────────────────────

이대로 등록할까요? (예 / 수정 / 취소)
```

### 1-2. 카카오 캘린더만 등록하는 경우

```
⚠️  카카오 캘린더는 등록 후 MCP로 수정할 수 없습니다.
    잘못 입력 시 카카오톡 앱에서 직접 수정해야 합니다.

📅 등록 정보 확인
─────────────────────────
제목:   {title}
시작:   {start_date} ({weekday}) {start_time}
종료:   {end_date} ({weekday}) {end_time}
장소:   {location}
알림:   {reminders_text}
반복:   {recurrence_text}
색상:   {color}
캘린더: 카카오
─────────────────────────

이대로 등록할까요? (예 / 수정 / 취소)
```

### 1-3. 둘다 등록하는 경우 (가장 신중)

```
⚠️  카카오 + 구글 동시 등록입니다.
    카카오는 등록 후 MCP로 수정할 수 없으므로 신중히 확인해주세요.
    
    등록 순서: 카카오 → 구글
    (카카오 실패 시 구글까지 자동 진행하지 않고 다시 묻습니다)

📅 등록 정보 확인
─────────────────────────
제목:   {title}
시작:   {start_date} ({weekday}) {start_time}
종료:   {end_date} ({weekday}) {end_time}
장소:   {location}
알림:   {reminders_text}
반복:   {recurrence_text}
─────────────────────────

이대로 등록할까요? (예 / 수정 / 취소)
```

## 2. 카카오 등록 전 사전 검증

카카오를 등록 대상에 포함하는 경우, 최종 확인 카드 출력 **전에** 다음을 검증한다. 위반 시 사용자에게 조정 요청한다.

### 2-1. 제목 길이 검증

```python
if len(title) > 50:
    return f"카카오는 제목 50자 제한입니다. 현재 {len(title)}자. 줄이시겠어요?"
```

### 2-2. 시각 5분 단위 검증

```python
if start_time.minute % 5 != 0 or end_time.minute % 5 != 0:
    # 가장 가까운 5분 단위 후보 2개 제시
    return "카카오는 5분 단위만 가능합니다. {nearest_floor}분 또는 {nearest_ceil}분 중 어느 쪽으로 할까요?"
```

### 2-3. 알림 개수 검증

```python
if len(reminders) > 2:
    return f"카카오 알림은 최대 2개입니다. {reminders} 중 어느 둘을 남길까요?"
```

### 2-4. 알림 시간 범위 검증

```python
for r in reminders:
    if r < -1440 or r > 43200:
        return "카카오 알림은 -1440분(1일후) ~ 43200분(30일전) 범위만 가능합니다."
    if r % 5 != 0:
        return "카카오 알림은 5분 단위만 가능합니다."
```

## 3. 컨펌 응답 처리

| 사용자 응답 | 처리 |
|----------|------|
| "예", "응", "어", "맞아", "맞습니다", "오케이", "OK", "등록", "확정", "ㅇㅇ" | → 5단계 MCP 호출로 진행 |
| "수정", "바꿔", "고쳐", "아니" + 수정 내용 | → 해당 슬롯 수정 후 다시 최종 확인 카드 |
| "취소", "관둬", "그만", "안 해" | → 등록 중단, 입력값 폐기, "취소되었습니다" 응답 |

**"수정" 응답 처리 예시**:

```
[사용자] 수정. 알림 1시간 전으로

[Claude] (reminders를 [60]으로 변경 후 다시 최종 확인 카드 출력)
```

## 4. MCP 호출 절차

### 4-1. 카카오 캘린더 호출

도구: `PlayMCP:KakaotalkCal-CreateEvent`

```yaml
title: "{title}"
time:
  startAt: "{YYYY-MM-DD}T{HH:MM}:00"   # 5분 단위
  endAt:   "{YYYY-MM-DD}T{HH:MM}:00"   # 5분 단위
  allDay:  {true|false}                 # 종일이면 시각은 00:00:00
description: "{description}"            # 선택, 5000자 이내
location:                               # 선택
  name:    "{location_name}"            # 100자 이내
  address: "{location_address}"         # 선택
reminders: [{minutes_1}, {minutes_2}]   # 최대 2개
recurrence: "{RRULE_string}"            # RFC 5545
color: "{COLOR_ENUM}"                   # 선택
```

### 4-2. 구글 캘린더 호출

도구: `Google Calendar:create_event`

```yaml
summary:   "{title}"
startTime: "{YYYY-MM-DD}T{HH:MM:SS}"
endTime:   "{YYYY-MM-DD}T{HH:MM:SS}"
timeZone:  "Asia/Seoul"
allDay:    {true|false}
description: "{description}"
location:  "{location_text}"
attendeeEmails: ["..."]                 # 선택, 구글 전용
addGoogleMeetUrl: {true|false}          # 선택, 구글 전용
overrideReminders:                      # 선택
  - method: "popup"
    minutes: {minutes_1}
  - method: "popup"
    minutes: {minutes_2}
recurrenceData: ["RRULE:..."]           # RFC 5545
colorId: "{1~11}"                       # 선택
```

### 4-3. 동시 등록 시 호출 순서

```
1. 카카오 먼저 호출
   ├── 성공 → 2번 진행
   └── 실패 → 사용자에게 "구글 캘린더는 어떻게 할까요? (계속 / 중단)" 묻기

2. 구글 호출
   ├── 성공 → 5번 결과 보고
   └── 실패 → 카카오만 등록된 상태 안내 + 사용자에게 재시도 여부 묻기
```

## 5. 결과 보고 포맷

### 5-1. 성공 (단일 캘린더)

```
✅ 구글 캘린더에 등록 완료

📅 부서 회의
   2026-05-14 (목) 15:00 ~ 16:00
   📍 본관 3층 회의실
   ⏰ 30분 전 알림
```

### 5-2. 성공 (둘다)

```
✅ 카카오 + 구글 캘린더에 등록 완료

📅 부서 회의
   2026-05-14 (목) 15:00 ~ 16:00
   📍 본관 3층 회의실
   ⏰ 30분 전 알림
   
[카카오] 등록 완료
[구글] 등록 완료 (이벤트 ID: {event_id})
```

### 5-3. 카카오 실패, 구글 처리 묻기

```
❌ 카카오 캘린더 등록 실패
   오류: {error_message}

구글 캘린더는 어떻게 할까요?
- "계속" → 구글에만 등록
- "중단" → 등록 중단
```

### 5-4. 둘다 실패

```
❌ 등록 실패
   카카오: {kakao_error}
   구글: {google_error}

다시 시도하시겠어요? (예 / 아니오)
```

### 5-5. 부분 성공 (카카오만)

```
⚠️ 부분 등록

[카카오] ✅ 등록 완료
[구글] ❌ 등록 실패: {error_message}

카카오는 등록되었지만 구글은 실패했습니다.
구글만 재시도하시겠어요? (예 / 아니오)
```

## 6. 절대 금지 사항

1. **컨펌 없이 MCP 호출 금지.** "예/응/등록" 등 명시적 승인이 있어야만 호출한다.
2. **카카오 제약 위반 상태로 호출 금지.** 50자/5분단위/2개알림 등 사전 검증 통과 후에만 호출.
3. **카카오 등록 후 자동으로 구글 등록 진행 금지.** 카카오 실패 시 반드시 사용자에게 묻는다.
4. **MCP 호출 결과를 임의로 해석해서 "성공"이라 보고하지 않는다.** 도구 응답을 그대로 신뢰하고, 오류 메시지를 사용자에게 그대로 전달한다.
5. **등록 실패 후 사용자 확인 없이 재시도 금지.** 반드시 묻고 재시도한다.

## 7. 나챗방 설정 확인 (캘린더 확인 카드와 한 번에)

나챗방 ① 또는 ②가 선택되었으면 최종 확인 카드의 `─────` 아래에 다음 블록을 붙이고, **한 번의 "예"로 캘린더 등록과 나챗방 설정을 모두 승인**받는다.

### 7-1. ① 아침 요약

```
💬 나챗방: 아침 요약에 포함
   매일 아침(현재 설정 9시 10분) 오늘 일정 요약에 "{HH:MM} {title}"로 함께 옵니다.
   새로 만드는 것은 없습니다.
```

### 7-2. ② 전용 알림 — 코워크 (직접 생성)

```
💬 나챗방 전용 알림 (예약 작업 새로 만들기)
   기간: {memo_start} ~ {memo_end}, 매일 {memo_time}
   문구: "{memo_text}"   ← (기본) 또는 사용자 지정
   ※ 카카오에도 등록하므로 아침 요약에도 함께 나옵니다.
```

### 7-3. ② 전용 알림 — 일반 채팅 (지시문 제공)

```
💬 나챗방 전용 알림
   기간: {memo_start} ~ {memo_end}, 매일 {memo_time}
   문구: "{memo_text}"
   ⚠️ 이 대화에서는 자동 발송 예약을 직접 만들 수 없습니다.
      등록 후 코워크에 붙여 넣을 지시문을 드립니다.
```

### 7-4. 실행 순서

```
1. 캘린더 등록 (카카오 → 구글)
   └── 실패 → 나챗방 설정 진행하지 않고 사용자에게 묻기
2. 나챗방 설정 (references/kakao-memo-notify.md 4~6절)
3. 결과 보고 (kakao-memo-notify.md 7절)
```
