# 나챗방 알림 규칙 (Kakao Memo Notify)

일정 등록과 함께 카카오톡 "나와의 채팅"(이하 나챗방)으로 안내 메시지를 받도록 설정하는 절차. 2단계 질문, 4단계 확인, 5단계 실행에서 이 파일을 따른다.

---

## 1. 두 가지 방식 (사용자에게는 쉬운 말로 설명)

| 방식 | 사용자용 이름 | 동작 | 조건 |
|------|------------|------|------|
| ① | **아침 요약에 포함** | 이미 있는 예약 작업 `kakao-calendar-daily-digest`가 매일 아침(현재 설정 오전 9시 10분) 카카오 캘린더의 오늘 일정을 읽어 "HH:MM 제목" 한 줄로 나챗방에 보낸다. 따로 만들 것이 없다. | 카카오 캘린더에 등록한 일정만 해당. 구글만 등록하면 이 방식은 제시하지 않는다. |
| ② | **전용 알림 만들기** | 이 일정만을 위한 예약 작업을 새로 만들어, 사용자가 정한 날짜·시각에 정해진 문구를 나챗방으로 보낸다. | 예약 작업 도구가 있는 환경(코워크)에서만 직접 생성. 일반 채팅에서는 붙여 넣을 지시문을 만들어 준다. |
| ③ | **안 받기** | 나챗방 안내 없음 | — |

**설명할 때 쓰지 말 것**: "digest", "MCP", "RRULE", "taskId" 같은 용어. 사용자에게는 "아침 요약", "전용 알림", "예약 작업"이라고만 말한다.

---

## 2. 언제 묻고, 언제 묻지 않는가

**항상 묻는다.** 2단계 통합 보강 질문에 "나챗방 안내" 항목을 매번 포함한다.

**묻지 않고 바로 반영하는 경우** (사용자가 처음부터 시킨 경우):

| 사용자 첫 발화 | 처리 |
|------------|------|
| "카카오 스케줄에 넣고 나챗방으로도 매일 9시에 알려줘" | 방식 ② 로 확정. 시각·기간·문구를 발화에서 추출. 빠진 것만 묻는다. |
| "나챗방에도 알려줘" (시각·기간 없음) | 나챗방을 원한다는 것은 확정. 방식(①/②)과 ②일 때의 시각·기간만 묻는다. |
| "아침 요약에 나오게만 해줘" | 방식 ① 로 확정. |
| "나챗방은 필요 없어" | 방식 ③ 으로 확정. |

처음부터 카카오 스케줄과 나챗방을 함께 시킨 경우, 질문과 확인은 **한 번에 묶어서** 하고, 사용자가 확인하면 캘린더 등록과 나챗방 설정을 **연달아 한꺼번에** 실행한다.

참고: 방식 ②를 고르더라도 카카오에 등록했다면 방식 ①의 아침 요약에도 자동으로 함께 나온다. 이 점을 확인 카드에서 한 줄로 알려 준다.

---

## 3. 방식 ② 전용 알림의 슬롯

| 슬롯 | 의미 | 결정 규칙 |
|------|------|---------|
| `memo_text` | 나챗방에 보낼 문구 | **사용자가 말한 문구가 1순위.** 사용자가 문구를 말하지 않았으면 기본 형식 `[D-N] 마감: {title}`을 쓰고 카드에 `(기본)`으로 표시한다. |
| `memo_time` | 보내는 시각 | 사용자 지정. 없으면 묻는다. 추측 금지. |
| `memo_start` | 첫 발송일 | 사용자 지정. 없으면 묻는다. |
| `memo_end` | 마지막 발송일 | 사용자 지정. 없으면 묻는다. |
| `memo_deadline` | D-N 계산 기준일 | 문구에 `D-N`이 있을 때만 필요. 사용자가 말한 마감일. 없으면 일정 시작일을 기준으로 하되 카드에 `(자동)` 표시. |

규칙:
- 문구는 200자 이내 (나에게 보내기 도구 제한).
- 문구에 `D-N`이 있으면 실행 시점마다 다시 계산하도록 지시문에 적는다. 마감 당일 문구가 필요한 기간이면 당일 문구(예: `[D-DAY] 오늘 마감: {title}`)를 사용자에게 확인한다.
- 마지막 발송일 이후에는 보내지 않는다는 안전 문장을 지시문에 항상 넣는다.

---

## 4. 실행 환경 판별

실행 직전에 도구 목록을 확인한다.

| 환경 | 판별 | 처리 |
|------|------|------|
| 코워크 | 예약 작업 생성 도구(`create_scheduled_task`, 보통 `mcp__scheduled-tasks__create_scheduled_task`)가 있다 | 방식 ②를 직접 생성한다 (5절). 방식 ①은 `list_scheduled_tasks`로 `kakao-calendar-daily-digest`가 있는지 확인한다. |
| 일반 채팅 | 예약 작업 생성 도구가 없다 | 캘린더 등록과 나챗방 즉시 발송은 가능하다. 매일 자동 발송(방식 ②)은 직접 만들 수 없다. 6절의 붙여 넣기용 지시문과 설정값을 출력한다. 방식 ①은 존재 여부를 확인할 수 없으므로 "아침 요약 작업이 켜져 있다면" 이라고 조건을 붙여 안내한다. |

**정직 원칙**: 만들지 않은 예약 작업을 "만들었다"고 말하지 않는다. 일반 채팅에서는 "이 대화에서는 자동 발송을 직접 만들 수 없어 코워크에 등록하셔야 합니다"라고 분명히 말한다.

---

## 5. 코워크에서 방식 ② 직접 생성

도구 스키마를 먼저 확인한다. 현재 확인된 파라미터: `taskId`, `fireAt`(1회 실행 시각), `description`, `prompt`, `notifyOnCompletion`.

- 반복 실행 파라미터가 스키마에 있으면 그것을 쓴다.
- 없으면 **발송일마다 1회성 작업**을 하나씩 만든다 (발송일이 14일을 넘으면 사용자에게 먼저 확인).

1회성 작업 값:

```yaml
taskId: "kakao-memo-{영문/숫자 요약}-{yyyyMMdd}"   # 같은 이름이 있으면 건너뜀(list_scheduled_tasks로 확인)
fireAt: "{yyyy-MM-dd}T{HH:mm}:00+09:00"
description: "나챗방 알림: {title} ({yyyy-MM-dd})"
notifyOnCompletion: false
prompt: (6절 지시문)
```

생성 결과는 도구 응답 그대로 보고한다. 일부만 성공하면 성공·실패한 날짜를 나눠 알린다.

---

## 6. 지시문 템플릿 (코워크 생성용 + 일반 채팅 붙여 넣기용 공통)

```
오늘은 "{title}" 나챗방 알림을 보내는 날입니다.
KakaotalkCal-GetCurrentTime 도구로 오늘 날짜와 현재 시각(Asia/Seoul)을 확인하세요.
{D-N이 있을 때만} 오늘부터 {memo_deadline}까지 남은 일수 N을 계산하세요.
오늘이 {memo_start}보다 이르거나 {memo_end}보다 늦으면 아무것도 전송하지 말고 종료하세요.
KakaotalkChat-MemoChat 도구로 카카오톡 나와의 채팅에 다음 메모를 전송하세요: "{memo_text}"
도구 오류가 나면 재시도하지 말고 조용히 종료하세요. 다른 작업은 하지 마세요.
```

도구 이름은 실행 환경에 보이는 정확한 이름을 쓴다. 코워크 기존 작업에서는 `mcp__{서버ID}__KakaotalkChat-MemoChat` 형태였다. 이름을 모르면 위처럼 기능 이름(`KakaotalkChat-MemoChat`)으로 적는다.

### 일반 채팅에서 함께 출력할 설정값

```
반복: 매일 {memo_time}
시작: {memo_start}
종료: {memo_end}
```

설정 메뉴 위치는 확인하지 못했다면 추측하지 말고 "코워크의 예약된 작업에 새 작업으로 등록하세요"라고만 안내한다.

## 7. 결과 보고 예시

### 코워크, 직접 생성 성공

```
✅ 카카오 캘린더 등록 완료
📅 {title} — {기간/시각}

💬 나챗방 전용 알림 예약 완료
   {memo_start} ~ {memo_end}, 매일 {memo_time}
   문구: "{memo_text}"
   (컴퓨터에서 Claude 앱이 켜져 있어야 제시간에 옵니다)
```

### 일반 채팅

```
✅ 카카오 캘린더 등록 완료
📅 {title} — {기간/시각}

💬 나챗방 전용 알림은 이 대화에서 직접 예약할 수 없습니다.
   코워크의 예약된 작업에 아래 지시문을 새 작업으로 등록해 주세요.
   [지시문]
   [설정값]
```

### 방식 ① 만 선택

```
💬 나챗방: 아침 요약에 포함
   매일 아침(현재 설정 9시 10분) 오늘 일정 요약에 "{HH:MM} {title}"로 함께 옵니다.
   따로 만들 것은 없습니다. (아침 요약 작업이 켜져 있어야 합니다)
```

---

## 8. 금지 사항

1. 사용자 확인 없이 예약 작업을 만들지 않는다. 캘린더와 같은 확인 카드 한 번으로 함께 승인받는다.
2. 기존 `kakao-calendar-daily-digest` 작업을 수정하거나 삭제하지 않는다.
3. 사용자가 말하지 않은 발송 시각·기간을 추측해 넣지 않는다.
4. 일반 채팅에서 예약 작업이 만들어진 것처럼 말하지 않는다.
5. 테스트로 나챗방에 메시지를 보내지 않는다. 사용자가 "지금 한 번 보내 줘"라고 할 때만 즉시 발송한다.
