# kakao-chat-schedule-register

채팅으로 말한 일정을 **카카오 캘린더·구글 캘린더에 등록**하고, 원하면 **카카오톡 나와의 채팅(나챗방)으로 안내 메시지**까지 받도록 설정하는 Claude 스킬입니다.

## 무엇을 해 주나요

- "내일 3시 회의"처럼 짧게 말해도 날짜·시각·제목을 뽑아 일정 카드로 보여 줍니다.
- 빠진 항목(종료 시각·알림·장소·반복)만 한 번에 묻습니다.
- 등록 직전에 확인 카드를 보여 주고, "예"라고 해야 등록합니다. (카카오 캘린더는 등록 후 수정이 안 되므로 경고를 함께 보여 줍니다)
- **나챗방 안내를 항상 묻습니다.**
  - ① 아침 요약에 포함 — 매일 아침 오늘 일정 요약에 함께 옵니다 (아침 요약 예약 작업이 있어야 함)
  - ② 전용 알림 — 정한 날·시각에 이 일정만 따로 메시지가 옵니다
  - ③ 안 받기
- 처음부터 "카카오 스케줄에 넣고 나챗방으로도 매일 9시에 알려줘"라고 하면 다시 묻지 않고 한꺼번에 처리합니다.
- 나챗방 문구는 **말한 그대로** 씁니다. 말하지 않으면 `[D-N] 마감: 제목` 형식을 씁니다.

## 필요한 것

| 항목 | 용도 |
|------|------|
| PlayMCP(카카오) 커넥터 | 카카오 캘린더 등록(`KakaotalkCal-CreateEvent`), 나챗방 발송(`KakaotalkChat-MemoChat`) |
| Google Calendar 커넥터 (선택) | 구글 캘린더 등록 |
| Claude 코워크의 예약된 작업 (선택) | 나챗방 **자동** 발송 |

## 일반 채팅과 코워크의 차이

| 기능 | 일반 채팅 | 코워크 |
|------|---------|-------|
| 캘린더 등록 | 가능 | 가능 |
| 나챗방에 지금 한 번 보내기 | 가능 | 가능 |
| 정해진 시각에 매일 자동 발송 | 직접 만들 수 없음 → 붙여 넣을 지시문을 줍니다 | 예약 작업을 직접 만듭니다 |

자동 발송은 컴퓨터에서 Claude 데스크톱 앱이 켜져 있어야 제시간에 실행됩니다.

## 설치

1. 이 저장소를 내려받아 폴더째 압축합니다 (`SKILL.md`가 폴더 바로 안에 있어야 합니다).
2. Claude 설정의 스킬 메뉴에서 업로드합니다.

## 사용 예

```
10월 20일까지 원고 보내기 카카오 스케줄에 넣고,
14일부터 매일 오전 9시에 나챗방으로도 알려줘
```

→ 일정 카드 확인 → "예" → 카카오 캘린더 등록 + 나챗방 전용 알림 설정(코워크) 또는 지시문 제공(일반 채팅)

## 파일 구성

```

references/tacit-defaults.md      자동 기본값 (종료 시각 등)

references/kakao-memo-notify.md   나챗방 안내 규칙 (아침 요약 / 전용 알림)
```

## 주의

- 카카오 캘린더 일정은 MCP로 등록한 뒤 수정할 수 없습니다. 고칠 때는 카카오톡 앱에서 직접 고치세요.
- 카카오 제약: 제목 50자, 시각 5분 단위, 알림 최대 2개.
- 나챗방 메시지는 200자 이내입니다.
